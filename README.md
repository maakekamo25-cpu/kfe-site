# KFE (Kits FastExpress)

Prototype marketplace for South Africans to buy Chinese products (sourced from Alibaba / Made-in-China), with ZAR landed-cost pricing (shipping, duty, VAT), cart, validated checkout and order timeline.

Open `index.html` in a browser. No build step.

## Status
Front-end prototype only. Prices, FX rate and duty rates are placeholders.

## Roadmap
- Backend (Node/Next.js or Shopify/WooCommerce) with server-side pricing
- Payment gateway (PayFast / Peach / Stripe) with 3-D Secure + webhooks
- Supplier sourcing via Alibaba API or China sourcing agent
- Escrow, QC workflow, SARS customs clearing
- POPIA privacy policy, admin 2FA, rate limiting
